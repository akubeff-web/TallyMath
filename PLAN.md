# План TallyMath

Тренажёр математики 5–8 классов для iPhone (SwiftUI, iOS 26). Вся логика — в пакете `MathCore`, интерфейс — в приложении `TallyMath`. Сборка и проверка — только в GitHub Actions.

## Структура

```
TallyMath/
├── project.yml                  описание проекта для XcodeGen (.xcodeproj не коммитится)
├── Packages/MathCore/           логика без SwiftUI/UIKit, собирается и тестируется и на Linux
│   ├── Sources/MathCore/
│   │   ├── Numbers/             Rational — точные дроби (пара целых, без Double)
│   │   ├── Expressions/         дерево выражения, разбор записи (Parser), вычисление
│   │   ├── Algebra/             нормальная форма многочленов и дробей с корнями, решатели
│   │   ├── Checking/            проверка шагов и ответа, простейший вид, типичные ошибки
│   │   ├── Topics/              темы 5–8 классов: генераторы, решения по шагам, уроки
│   │   ├── Editor/              модель редактора записи (дробь, степень, корень, …)
│   │   └── Progress/            статистика, слабые места, повторение по интервалам
│   └── Tests/MathCoreTests/     юнит-тесты: минимум 5 примеров на каждую тему
├── TallyMath/                   приложение
│   ├── App/                     точка входа, состояние, launch-аргументы для скриншотов
│   ├── Design/                  палитра, фон, стекло, Bit (рисуется Shape/Canvas)
│   ├── Components/              дроби, строки записи, клавиатуры, кнопки
│   ├── Screens/                 Главная, Тренировка, Итоги, Уроки, Решаю сам, Курс, Статистика, …
│   └── Resources/               Assets (иконка), why.json («Зачем это нужно»)
├── TallyMathTests/              тесты приложения (запуск на симуляторе)
├── scripts/                     иконка, проверка Swift-сниппетов, упаковка .ipa
├── design/                      макеты этапа 0
└── .github/workflows/build.yml  тесты, скриншоты, .ipa, Release
```

## Шаги (каждый — отдельный коммит)

1. MathCore: точные дроби, дерево выражения, разбор записи, вычисление.
2. MathCore: нормальная форма (многочлены, рациональные дроби, корни), сравнение строк.
3. MathCore: решатели — уравнения, системы, неравенства, формы ответа.
4. MathCore: проверка шага и ответа, «верно, но сократи», типичные ошибки и подсказки.
5. MathCore: темы 5–8 классов с генераторами, решениями по шагам и уроками.
6. MathCore: статистика, слабые места, «не понял», повторение 1–3–7–14–30 дней.
7. MathCore: модель редактора записи.
8. Приложение: проект, дизайн, Bit, компоненты.
9. Приложение: экраны.
10. Иконка, «Зачем это нужно» (только проверенные источники), проверка сниппетов.
11. CI до зелёного, скриншоты, Release с .ipa.

## Принципы проверки

- Числа только точные (`Rational`), никаких `Double` в проверке.
- Шаг верный, если он равносилен предыдущей строке: для выражений — равенство нормальных форм, для уравнений и неравенств — равенство множеств решений.
- Ошибка распознаётся так: к предыдущей строке применяются «неправильные» преобразования (сложить верхи и низы, умножить только верх, потерять минус перед скобкой…). Если новая строка совпала с одним из них — называем ошибку.
- Если строку нельзя проверить надёжно — статус «не удалось проверить», а не догадка.
