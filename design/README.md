# Дизайн-превью (этап 0)

- `bit-states.svg` / `.png` — персонаж Bit в 6 состояниях, светлая и тёмная тема.
- `screens.svg` / `.png` — главная (темы с кнопкой «Урок», слабая тема), тренировка (кнопка «Объясни»), верный ответ («Как решать правильно», «Похожий пример», «Полное решение»), ошибка (уровень 1, «Понял» / «Не понял»).
- `screens-learning.svg` / `.png` — урок темы (правило и 2 примера, «Ещё пример»), уровень 2 (по шагу: стрелки, откуда множитель, почему не другое число, проверка), уровень 3 (пример попроще, вводишь множитель и результат сам), полное решение со стрелками.
- `screens-stats.svg` / `.png` — вкладка «Статистика» (тепловая карта таблицы умножения, точность по темам дробей), экран темы (тренд, частые ошибки, «Повторить урок»), итоги сессии из 10 примеров.
- `screens-solve.svg` / `.png` — «Решаю сам»: тетрадь по шагам со статусами строк и клавиатурой 5–6 класса (дробь, смешанное число, пометка множителя «×n»), ошибочный шаг с подсказкой Bit (решение скрыто), режим «Быстрый» с клавиатурой 7–8 класса, «Свой пример».
- `screens-course.svg` / `.png` — вкладка «Курс» (все темы 5–8), карточка темы с блоком «Зачем это нужно», черновик (PencilKit).
- `src/generate.py` — генерирует все SVG (`python3 design/src/generate.py`).
- `src/render.js` — рендерит SVG в PNG через Chromium/Playwright (`node design/src/render.js`).

Шрифт в превью — Inter вместо SF Pro (SF есть только на устройствах Apple).

## Иконка

- `icon/AppIcon-1024.png` — иконка приложения 1024×1024, без альфа-канала (так требует iOS). Сделана из присланного образца: уменьшена с 1254 до 1024.
- `icon/icon-sizes-preview.png` — как иконка выглядит в маске iOS на размерах 180, 120 и 87 px, на светлом и тёмном фоне.

Когда появится приложение, этот файл ляжет в `Assets.xcassets/AppIcon.appiconset/`.

## Источники в макете «Зачем это нужно» (тема «Проценты»)

Проверены 13.11.2026, каждая страница открыта и пересказ сверен с текстом:

- https://qna.habr.com/q/965239 — веб-разработчик: за пять лет математика понадобилась в основном для скидок и суммы корзины.
- https://qna.habr.com/q/485721 — мнения расходятся: одни считают, что в мобильной и веб-разработке хватает арифметики, другие приводят анимацию, сложные проценты, статистику в трекере пробежек.
- https://inventwithpython.com/blog/how-much-math-do-i-need-to-know-to-program-not-that-much-actually.html (2012) — для программирования в основном хватает арифметики; процент считают умножением на десятичную дробь.

Не использованы (страница не открылась, 403): обсуждения на forums.macrumors.com и applevis.com.
