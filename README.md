# TallyMath

Тренажёр математики 5–8 классов для iPhone. Под иконкой — **Tally**. Случайные примеры, проверка ответа и каждого шага решения, объяснения в трёх уровнях подробности, статистика слабых мест, повторение освоенных тем и персонаж Bit.

Только для личного использования: без сети, аккаунтов и аналитики. Прогресс хранится в файле на телефоне.

## Что умеет

- **Тренировка**: 10 примеров, своя стеклянная клавиатура, дроби «столбиком», проверка ответа. «Верно, но сократи», «выдели целую часть» и т. п. — отдельные статусы.
- **Объяснения**: уровень 1 — шаги правилами на числах примера; «Не понял» → уровень 2 — по одному шагу, крупные дроби и стрелки «×2», откуда множитель и почему не другое число; ещё раз «Не понял» → уровень 3 — тот же приём на примере попроще, вводишь сам.
- **Решаю сам**: тетрадь, строки решения одна под другой. Режим «По шагам» проверяет каждую строку, «Быстрый» — итог. Первая ошибочная строка выделяется, Bit называет ошибку, но решение показывает только по кнопке.
- **Свой пример**: вводишь пример из домашки — приложение определяет класс и тему, считает ответ и шаги. Неподдерживаемое называет честно.
- **Курс**: все темы 5–8 классов сразу. У каждой темы — урок, тренировка, «Решить самому» и блок «Зачем это нужно» с реальными источниками.
- **Статистика**: тепловая карта таблицы умножения, точность по темам, частые ошибки.
- **Повторение**: тема, решённая на 10/10, возвращается через 1, 3, 7, 14, 30 дней (дальше раз в два месяца). Две ошибки и больше из 5 — интервал снова короткий.
- **Черновик**: свободное рисование пальцем или Apple Pencil, не проверяется.

## Как устроен проект

Логика и интерфейс разделены: вся математика — в пакете `MathCore` (без SwiftUI и UIKit, собирается даже на Linux), приложение только показывает и передаёт ввод.

### `Packages/MathCore` — логика

| Файл | Что делает |
|---|---|
| `Package.swift` | Описание пакета: библиотека `MathCore` и тесты. |
| `Numbers/Rational.swift` | Точные дроби (пара целых, всегда сокращены). Ошибки арифметики: переполнение, деление на ноль. НОД, НОК, простые множители. |
| `Expressions/Expr.swift` | Дерево выражения. Хранит и форму записи (дробь, смешанное число, десятичная), потому что «простейший вид» зависит от формы. `Statement` — строка целиком: уравнение, цепочка, ответ «x₁ = 2 или x₂ = 3», промежутки. |
| `Expressions/Parser.swift` | Разбор записи в дерево: дроби, степени, корни, модуль, проценты, «или», промежутки, системы, «ост.». |
| `Expressions/Printer.swift` | Обратно: дерево → запись (минус «−», степени надстрочными цифрами). |
| `Algebra/Poly.swift` | Нормальная форма: многочлены с точными коэффициентами и корнями (√2, √3 …), рациональные дроби. Так проверяется, что две записи равны. |
| `Algebra/Evaluate.swift` | Вычисление дерева в нормальную форму; сравнение двух выражений; подстановка значений. |
| `Algebra/Solve.swift` | Решатели: линейные и квадратные уравнения, уравнения с дробями (посторонние корни), с модулем, неравенства и промежутки, системы (метод Гаусса). |
| `Checking/Mistake.swift` | Виды типичных ошибок, реплика Bit и подсказка к каждой; статусы строки. |
| `Checking/Mutations.swift` | «Неправильные» преобразования (сложить верхи и низы, умножить только верх, потерять минус перед скобкой…). Если ответ совпал с одним из них — понятно, какую ошибку назвать. |
| `Checking/Checker.swift` | Проверка ответа и «простейшего вида» для каждого вида ответа. |
| `Checking/LineChecker.swift` | Проверка тетради «Решаю сам» построчно; вспомогательные строки (D = …); «не удалось проверить», если надёжно нельзя. |
| `Checking/StepAnswer.swift` | Проверка ответа на вопрос шага уровня 3. |
| `Topics/Topic.swift` | Модель темы, задания и шага решения (данные для всех трёх уровней объяснения); генератор случайных чисел с зерном. |
| `Topics/Steps.swift` | Общие шаги: порядок действий, сложение дробей со стрелками, сокращение и целая часть. |
| `Topics/Grade5…8.swift` | 54 темы 5–8 классов: генератор примеров, решение по шагам, правило урока. |
| `Topics/Course.swift` | Весь курс, разделы, уроки. |
| `Topics/CustomProblem.swift` | «Свой пример»: определение темы, ответ, шаги. |
| `Progress/Progress.swift` | Статистика, слабые места, «Не понял», повторение по интервалам, подбор примеров без повторов подряд. |
| `Editor/MathEditor.swift` | Модель редактора: шаблоны дроби, степени, корня, модуля, системы; курсор; превращение в текст для разбора. |
| `Editor/MathLayout.swift` | Разметка записи для отрисовки (дроби «столбиком», показатели, корни). |
| `Tests/MathCoreTests/*` | Юнит-тесты: арифметика, разбор, решатели, проверка, ошибки, каждая тема на 30 случайных примерах, прогресс, редактор. |

## Сборка

Mac не нужен — всё делает GitHub Actions (`.github/workflows/build.yml`). Сборка запускается на каждый push и вручную (Actions → Build → Run workflow):

1. Выбирается установленный Xcode 26, ставится XcodeGen, генерируется проект.
2. `swift test` — тесты MathCore; проверка Swift-сниппетов.
3. `xcodebuild test` — тесты приложения на симуляторе iPhone.
4. Скриншоты всех экранов в светлой и тёмной теме — артефакт **screenshots**.
5. Неподписанная сборка Release для `iphoneos` и упаковка в `TallyMath.ipa` — артефакт **TallyMath-ipa**.
6. При теге `v*` — GitHub Release с `.ipa`.

Логику можно проверить и без Mac: в папке `Packages/MathCore` выполнить `swift test` (нужен Swift 6 для Linux или macOS).

## Установка через SideStore

`.ipa` не подписан — подписывает SideStore на телефоне.

1. Установи SideStore на iPhone по инструкции на сайте SideStore (нужен один раз компьютер для первичной настройки).
2. Скачай `TallyMath.ipa` со страницы Release (или из артефакта **TallyMath-ipa** в Actions, он придёт zip-архивом — распакуй).
3. Открой файл на iPhone → «Поделиться» → SideStore, или в SideStore нажми «+» и выбери `.ipa`.
4. SideStore подпишет приложение твоим Apple ID. Бесплатная подпись действует 7 дней — SideStore обновляет её сам, когда телефон в той же сети, что и настроенный сервер, или вручную кнопкой Refresh.

Capabilities и entitlements в проекте не используются, поэтому бесплатной подписи хватает.
